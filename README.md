# 都市計画 復習資料

都市計画科目共通問題の復習ノート。
教科書『都市計画とまちづくりがわかる本』準拠、東科大過去問出題分析付き。

## 構成

| PART | 内容 | 節番号 |
|------|------|--------|
| Ⅰ | 都市計画の歴史と思想（海外） | 01–09 |
| Ⅱ | 日本の都市計画の歩み | 10–15 |
| Ⅲ | 建築基準法の基礎 | 16–21 |
| Ⅳ | 都市計画法のしくみ | 22–30 |
| Ⅴ | 世界の制度と現代の課題 | 31–40 |
| Ⅵ | まちづくりの担い手とルール | 41–44 |
| Ⅶ | 分野別まちづくり | 45–50 |
| Ⅷ | 実践と現代課題 | 51–56 |
| Ⅸ | まちづくりのこれから | 57–60 |

年表・人物表・制度比較表・日英対訳用語集・東科大過去問出題頻度分析を含む。

## 使い方

- 左上キーワード検索（Ctrl/Cmd + K で急速）
- Enter で検索実行、Esc でクリア
- 検索対象：すべての節カード + 年表/人物/制度比較/用語集の表セクション

## 出典
